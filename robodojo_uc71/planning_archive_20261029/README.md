# uc7.1 Astra high — RoboDojo

Planning workspace for **native RoboDojo Make Toast, Standard version** (`make_toast`). The user requested a plan before implementation and chose **both native ARX arms and all three RGB cameras**, retaining the same information categories as the LIBERO-10 tests.

Read [the implementation and test plan](PLAN.md), [the model-input contract](INPUT_CONTRACT.md), and [planning provenance](planning_manifest.json). Independent source/contract review is recorded in [planning_review.json](planning_review.json).

Current status: **plan prepared; implementation and live test not started**. No simulator was launched, no planning/execution model request was sent, and no dependencies/assets were installed for this task. This turn creates planning documents only. All future adapter code, environment configuration, validation, previews and runs belong under this directory; the existing LIBERO uc7.1 release remains unchanged.

The first proposed evaluation is one approved standard-layout episode, seed-directory0/layoutID0, after installation, adapter validation, actual preview and initial-plan review. It is a pilot, not a 25-episode Standard sweep or a reproduction of the linked Astra-medium report. The standing requirement for preview and explicit test-start approval remains in effect.
