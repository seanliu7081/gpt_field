Drawer003：自体分离和空间支持修复结果

结论
起点误拒绝已经修复。Astra 可以返回路径，但仍会漏判真实环境碰撞；
DepthPro 补上可见空间支持后，单张图像仍不足以支持这组全臂运动。
这次修复解决了场接入问题，没有把预测几何变成准确的真实场景。

改动范围
所有新增代码和结果位于 scene_test/field_planning_v2；原控制代码、原模型
预测和上一轮实验均保留。只使用 drawer003 的关闭 step60、打开 step552
两个快照，保留全部 13 个原生机器人碰撞几何体。没有新增视觉推理。

Astra：从原始模型 CSG 中移除顶层 robot_* 组件，保留其他组件、重叠部分
和差集。关闭/打开快照分别移除 6/14 个机器人组件。新规划查询使用原边界
内的环境解析场，因此这是显式派生的新规划表示，而非原 2 mm 网格不变。

DepthPro：保留原预测深度和 K_pred，恢复预测表面前方的可见射线支持；
已知机器人投影参与自体歧义与遮挡处理。已知相机内参只用于自体像素关联，
没有用它校正预测深度或重新投影预测几何。视野外、遮挡后方和未知区域仍
保持未知。原生机器人初始体积单独标为 SELF 先验，没有向外膨胀。
该先验明确假定初始机器人与环境不相互穿透且配准有效；它不是视觉观测。

复测设计
与上一轮完全相同的起终点、原生表面采样、规划参数和随机种子：
每快照 10 组起终点 × 2 个种子，每方法总计 40 次查询。
先保存并校验全部 80 条预测规划记录，再读取 LIBERO 真值评分与运行对照。
机器人表面采样覆盖半径不超过 5 mm，规划边检查间隔不超过 0.025 rad；
真值评分关节检查间隔不超过 0.005 rad。结果是有限采样验证，不是连续证明。

结果（每行 20 次查询）
场景     方法       返回路径   真值采样通过   真值碰撞   起点拒绝   目标拒绝
关闭     Astra      20         18             2          0          0
打开     Astra      20         14             6          0          0
关闭     DepthPro    0          0             0          0         20
打开     DepthPro    0          0             0          0         20
关闭     真值对照   18         18             0          0          2
打开     真值对照   14         14             0          0          6

上一轮两种预测场都在起点拒绝全部查询。现在四个方法/快照组合的起点都通过。
DepthPro 起点的全部 172,411 个表面点由 SELF 先验支持，不能解读为相机新增
了 100% 的场景覆盖。Astra 起点则由去除机器人后的环境场支持。

Astra 剩余问题
40 条返回路径中 32 条通过，8 条碰撞。8 条来自 4 组起终点各两个种子；
这 8 个目标状态在真值中本身也碰撞，正确行为应该是拒绝这些目标。
关闭时 base_negative 撞 wine_rack；打开时 shoulder_positive、elbow_negative、
wrist_negative 撞 wooden_cabinet。
事后诊断重现全部碰撞：实际接触位置在 Astra 场里仍被判为空闲，对应隐式
场值约 +50 至 +151 mm；同一碰撞姿态的全部机器人表面样本也被判为空闲。
这证实这些位置存在预测场景几何不匹配，不能只归因于路径采样间隔。
这些数值是预测隐式场值，不是全场重建误差或真实物理间隙。

打开时 base_negative 的两个种子均触发 RRT 绕行，并通过真值采样检查。
真值对照可直接连接同一起终点，因此该结果证明修复后系统能够搜索并返回
有效绕行路径，但不能据此认为这次绕行在真实场景中必要或最优。

DepthPro 剩余问题
40 个目标姿态都仍包含未知表面样本。关闭快照未知比例范围 2.89%–58.64%，
打开快照 6.73%–59.08%；主要来自视野外及原机器人造成的遮挡。
这不是仍在把全部未保存体素误判未知：例如关闭 base_positive 目标已有
25,988 个样本由恢复的可见射线支持，但另有 67,324 个未知样本。
真值对照能完成其中 32 次查询；DepthPro 当前仍无法接受这些已知可行查询。
要支持这些运动，需要额外的可观测空间信息或明确验证过的补全假设；
不能通过把未知区域全部设为空闲来宣布修复成功。

验证和完整性
87 项新旧主测试通过，另有 2 项图例回归测试通过。
842 个基线文件的最终哈希保持一致；规划与评分的源文件、输入及结果校验通过。
预测规划耗时 312.70 s，独立真值评分与对照耗时 51.87 s；这是离线批量实验
耗时，不是 drawer003 的机器人控制时间。
