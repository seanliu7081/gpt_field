Use fresh output directories; existing results are never overwritten. The plan
command reads the old robot-only packages and the new sensor-only calibration
exports in preparation_001. Each exported calibration includes its source hash
and the explicit restricted use of known rig K for self-image association.

The two sources produce different planning representations:
  Astra: environment-only analytic CSG, with derived JSON and component log.
  DepthPro: projective depth, visibility support, unknown states and SELF prior.
The projective residual is not an ESDF. Its Euclidean clearance lower bound is
reported as zero, and SELF support does not imply observed scene free space.

Read PROTOCOL.txt for the frozen comparison design. plans.json includes every
endpoint decision and support-layer diagnostic. field_provenance.json records
consumed hashes and map changes. metrics.json includes post-plan original LIBERO
collision checks and paired truth-planner outcomes. The figures separate start
classification changes from actual returned-path validity.

The authoritative figures for this run are in runs/analysis_002. analysis_001
is preserved but its outcomes legend omitted the gray refusal category. The
new plot_results_complete.py fixes only legend selection; frozen original
plot_results.py and both earlier experiment manifests remain unchanged.
