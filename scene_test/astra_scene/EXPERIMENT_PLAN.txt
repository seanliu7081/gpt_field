单张 RGB → Astra 隐式场 → 保存网格 → 从场重建
===========================================

用户明确要求由 Astra 生成场，并测试重建误差。本实验独立新增在
scene_test/astra_scene，不修改原项目及完成的 rgb_scene 实验。

输入沿用 rgb_scene/inputs_001 的三张 512×512 RGB。每张独立请求；
不输入另一视角、历史帧、DepthPro 预测、深度、相机真值、尺寸、
LIBERO 资产文件或场景状态。场景标签只保存在实验日志中。
gpt-6-astra，medium reasoning，既有 ChatGPT subscription OAuth；
不使用 API key、不切换模型、不因评分低重问或修正输出。

Astra 输出什么
---------------
Astra 直接输出 JSON 定义的连续三维隐式标量场。基元是定向长方体、
球、封闭圆柱；位置、方向、尺寸和组合关系全部由 Astra 推断。
并集 min(a,b)，交集 max(a,b)，差集 max(a,-b)。最多 32 基元和
32 组合节点，所有节点必须可达。单位米，相机 CV 坐标 x右/y下/z前。
焦距估计仅作为模型元数据；主评分使用真实相机射线，不以真实焦距
修正模型几何。禁止执行模型生成的 Python 等代码。

这是 CSG 隐式场，具有明确的零等值面；组合后的数值不保证处处为
最近表面的欧氏有符号距离。它不同于上一轮 DepthPro 投影 TSDF。
因此本实验不是只替换视觉模型、其余完全相同的严格消融；可以用
相同输入和同一真值指标比较最终几何，但需披露表示和容量差异。
模型可能猜测隐藏表面；猜测不等于观测，本轮评分不验证这些背面。

保存与解码
----------
默认 4、2 mm 网格，公共 4 mm 格点对齐，32 cell 分块。
各块采用四个 CPU worker 独立计算并按固定顺序收集；正式构建前
验证与单 worker 的数值和解码结果一致，不改变场或网格规则。
利用场的 1-Lipschitz 性质，仅跳过可证明不含零面的块；其余保存
实际 float32 标量和网格变换，再从磁盘数组独立提取零等值面。
跳过块不是未知空间；该机制是零面提取的存储优化，不是感知证据。
解码阶段不得读取原始 JSON 场、图片、深度或真值。
模型边界之外不补真值；资源超限、输出格式失败、空重建均如实保留。

评分
----
A：原始解析 CSG 的首个射线交点与真实可见几何比较。
C：实际从保存场恢复的 mesh，与同一真实相机射线深度比较。
两者采用 references_004 的精确图像时刻真值，无尺度或位姿对齐。
统计整图、非机器人区域、目标碗及柜体可见区域。报告命中 MAE/P95、
覆盖率，以及全部有效 GT 像素分母下的 ≤1/2/5/10 mm 通过率。
未命中计为阈值失败，不能通过丢弃难点改善得分。

B：保存和解码的额外损失。使用仅由模型包围盒定义的六个外部视角，
每视角 64×64 射线，比较原始解析 CSG 与解码 mesh 的首交点。
报告命中误差、原始表面的覆盖、错误新增命中和全参考阈值通过率。
这是多视角射线指标，不与上一轮双向面积采样表面均值混称同一指标。
六视角不能穷尽所有表面/内部腔体，也不能证明拓扑无损。

几何表示、网格间距与评分规则在读取 Astra 实际结果前确定；分块并行
只改变执行方式，另有逐元素一致性验证。先验证解析场、射线与序列化
数值测试，再进行三次独立推断；不做依赖真值的模型输出修复。
保存提示词、schema、请求/响应、token 用量、字段、配置和源码哈希。
凭据和鉴权头不得进入任何实验日志。失败尝试独立留存。
