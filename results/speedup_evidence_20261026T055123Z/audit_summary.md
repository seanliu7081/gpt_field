# P1 联合审计（历史证据，2026-10-26）

本轮选择 **v7 上的纯 I/O 候选**：A 为按冻结清单重建的 user-check v7 与共同服务计时；B 仅增加已经存在的紧凑展示录像和外部状态快照节流。控制 RGB、模型输入、动作、内部反馈、原始日志及成功判据必须保持等价。该选择值得开展工程验证，但历史证据尚不能证明新候选提高 S300。

## 感知、检查与证据链

本次没有经过控制器、状态和图像一致性核验的新真值重放。因此分轴定位误差、可行抓取区域命中和声明不确定性覆盖率均为 **unknown**，不以物体中心代替抓点真值。当前对象 ID、OBB 和目标是模型假设；低重投影误差或模型声称存在空域不能证明语义对应或可通行。r7 记录的局部姿态更新接受数为 0，参考失败包括纹理不足、对应歧义和遮挡；本轮不据此直接升级双目主路径。

对未真正执行的拒绝动作，正确拒绝／误拒绝保留 unknown。释放来源丢失、空手闭合误建生命周期和取景目标前置循环有具体代码与时序证据；它们与几何反事实标签分开。r11 的恢复链为：真实跟踪异常 → 自动取景候选但未执行 → 模型普通动作上退 → 新 RGB → 模型改几何／动作 → 仍未完成操作。仅中间回退链得到验证，完整恢复链没有通过。

选定 40 个当前结构化模型输入未出现 `answer_key/physical_truth/contact_identities/object_poses/reward/libero_success/task_predicate` 字段。此检查不能单独证明所有自由文本绝无泄漏；本轮审计脚本不导入策略，不向线上状态或提示词写审计数据。后续新候选还须验证实际请求等价。

## 本轮决定与反证

**continue：v7 纯 I/O。** 冻结模型、输入历史、控制逻辑和审核语义；先对保存输入验证请求内容、动作和事件顺序相同，再测真实录像／持久化关键路径。若 I/O 适配改变了模型输入、恢复所需内部更新、动作或 raw 判据，等价性失败；若真实 I/O 总成本未降低，则不当作提速模块。离线回放成功只证明行为／组件成本，不计新独立成功。

**freeze：本轮 v3 完整恢复扩展、组合程序与三角化主路径。** 原因是尚无自动新证据→动作修正→对象操作完成的有效链，而存在已确认的接口与状态依赖。这里是候选范围决定，**不是**把历史修复算作本轮“两轮失败”或消耗本轮运行额度。已修的空手闭合和动作来源行为可做定向验证，不重复建设。本轮主要候选冻结后，其他路线仅继续离线分析，不自动启第二在线候选。

**inconclusive：S300、完整任务速度与泛化。** 本轮 P1 没有新增在线成绩。只有共同服务时钟、相同审核条件下的新配对完成结果才能晋级；未启动或缺权限单元必须明确保留，不填成失败或成功。

## P2 离线真实展示 I/O 补充实测

固定历史 v7 t1 的第 0–119 步公共 RGB、动作与反馈，使用同一输入摘要，真实 ffmpeg 按 A1/B1/B2/A2 顺序编码。A 两次总展示墙钟为 10.851／10.526 秒，B 为 2.705／2.737 秒；中位数 10.689 → 2.721 秒，下降 **74.55%**。计时含创建、绘制、编码写入、终帧和同步 encoder drain，公共输入载入和 ffprobe 验证另列。四次 input hash 前后相同、源码哈希不变、render errors=0，ffprobe 帧数吻合。A 为 582 展示帧、B 为 122 帧，两者都覆盖全部 120 条真实保存动作；减少的是展示重复和布局，未改变策略图像。

该结果仅证实展示组件成本降低，不是整任务提速或新成功。未运行模型、策略 act 或仿真，不消耗在线运行额度；也未单独测快照节流收益。详见 `display_io_benchmark.json`、`mechanism_trace.jsonl` 与 `display_io/` 下四份视频和原始 attempts.jsonl。复现脚本 `tooling/benchmark_display_io.py` 要求新输出目录，拒绝覆盖历史产物。
